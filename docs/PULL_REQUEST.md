# feat: веб-GUI для analyzer.sh — аудит веб-ресурсов в браузере

## Что сделано

Добавлен браузерный интерфейс для `analyzer.sh`: вместо запуска из
терминала — форма ввода URL, карточки метрик соединения, таблица
заголовков и полный JSON-отчёт. Сервер написан на **стандартной
библиотеке Python 3**, новых зависимостей у репозитория не появляется.

## Состав изменений

| Файл | Назначение |
|---|---|
| `gui/server.py` | HTTP-сервер GUI (stdlib `http.server`, многопоточный): статика + JSON API |
| `gui/static/index.html` | одностраничный интерфейс (HTML/CSS/JS без фреймворков) |
| `tests/run_gui_tests.sh` | смоук-тесты GUI (9 групп, 21 проверка) |
| `docs/GUI.md` | документация: запуск, API, безопасность |
| `docs/PULL_REQUEST.md` | это описание |
| `README.md` | раздел о GUI и обновлённая структура репозитория |

## Возможности

* **Форма аудита**: URL + опции (общий таймаут, таймаут соединения,
  максимальный размер тела, следование редиректам);
* **Карточки метрик**: DNS, TCP, TLS, TTFB, общее время;
* **Сводка**: статус `success`/`partial`/`error`, HTTP-код, редиректы,
  человекочитаемая расшифровка кодов возврата analyzer.sh;
* **Заголовки и содержимое**: `Content-Type`, `Server`, HSTS,
  `Content-Length`, `<title>`, размер тела, признак сжатия;
* **JSON-отчёт** с кнопкой «копировать» — та же схема, что у
  `analyzer.sh --json-only` (docs/ANALYZER.md).

## HTTP API

* `POST /api/audit` — `{url, timeout, connect_timeout, max_size,
  follow_redirects}` → `{ok, exit_code, report, stderr, duration}`;
* `GET /api/health` — живость сервера и доступность analyzer.sh.

API можно использовать и без браузера (curl, скрипты) — см. docs/GUI.md.

## Безопасность

* URL и опции передаются analyzer.sh **только массивом аргументов**
  (`subprocess.run` без `shell=True`) — инъекции команд исключены;
* управляющие символы в URL → HTTP 400; валидация схем — в analyzer.sh
  (запрещённые `file://`, `javascript:` и др. → exit 3);
* режим `--json-only`: артефакты аудита на диск не пишутся;
* лимиты: таймаут ≤ 120 с, размер ≤ 100 МБ, ≤ 4 одновременных аудитов
  (сверх лимита — HTTP 429), жёсткий таймаут субпроцесса;
* субпроцесс получает минимальное окружение (`PATH`, `HOME`, `TMPDIR`,
  `NO_COLOR=1`).

## Тестирование

```
$ ./tests/run_gui_tests.sh
Итог: PASS=21 FAIL=0
Все проверки пройдены.
```

Покрыто: выдача страницы, `/api/health`, успешный аудит (метрики, title,
отсутствие артефактов), HTTP 404 → `partial`, запрещённая схема (exit 3),
пустой URL / битый JSON (HTTP 400), неизвестный маршрут (404),
`--follow-redirects` через API. Существующий набор `tests/run_tests.sh`
не затронут.

## Как запустить

```bash
python3 gui/server.py            # http://localhost:8000/
```

## Совместимость

* analyzer.sh не изменялся — GUI использует его публичный контракт
  (`--json-only`, коды возврата);
* CLI-режимы обоих инструментов работают как раньше.
