# Интерактивный поиск по адресам (`addr`)

Адрес в системе — здание/помещение организации (город, улица, дом).
В интерфейсе сайта адреса показаны на карте (`/cabinet/map`) и в списках
организаций. Команды `addr` делают то же самое из консоли и умеют
интерактивно выбирать адрес для дальнейшей работы.

## Команды

```bash
# Поиск по тексту (город, улица, дом, название) по ВСЕМ организациям
python3 f2c_inventory.py addr search "Ленина"

# Интерактивный выбор из найденного (стрелки ↑/↓, живой фильтр, Enter)
python3 f2c_inventory.py addr search "Москва" --interactive

# Поиск только в одной организации + показать оборудование выбранного адреса
python3 f2c_inventory.py addr search "Свободы" --org 10 --interactive --show-equipment

# Все адреса (или одной организации), выгрузка в CSV
python3 f2c_inventory.py addr list
python3 f2c_inventory.py addr list --org 10 --csv addresses.csv

# Пошаговый выбор: организация → адрес (для дальнейших действий)
python3 f2c_inventory.py addr pick

# Карточка конкретного адреса + оборудование на нём
python3 f2c_inventory.py addr show 101 --equipment
```

## Как работает поиск

1. Инструмент получает список организаций (`GET /api/organizations`);
2. для каждой организации запрашивает адреса
   (`GET /api/organizations/{org}/addresses`);
3. ранжирует адреса по совпадению с запросом: точное вхождение строки,
   совпадение слов, совпадение в адресных полях
   (`full_address`/`address`/`street`/`city`/`name`);
4. выводит результат, а в режиме `--interactive` открывает меню выбора
   с живым фильтром — можно продолжать печатать, список сужается на лету.

В консоли выбор выглядит так:

```
▶ Найденные адреса
↑/↓ — выбор · текст — фильтр · Enter — выбрать · Esc — очистить/отмена
 ▶ #101 г. Москва, ул. Ленина, д. 5, стр. 1  [ГБОУ Школа № 1557]
   #103 г. Зеленоград, пр-т Мира, д. 2  [Колледж № 32]
```

В скриптах и cron (когда нет терминала) меню автоматически превращается
в нумерованный список, а `--interactive` — в чтение номера из stdin:

```bash
printf '1\n' | python3 f2c_inventory.py addr search "Ленина" --interactive
```

## Типовые сценарии

- **Найти, где стоит оборудование**: `addr search "<улица>" --show-equipment`.
- **Подготовить перенос карточки**: выбрать адрес через `addr pick`
  (скопировать его ID) и выполнить `card <id> transfer --to <ID>`.
- **Проверить адреса перед инвентаризацией**: `addr list --csv` и свести
  с фактическим списком зданий.

## Если адреса не находятся

- Убедитесь, что вы вошли: `login` и `status`.
- Проверьте карту API: `api-map --filter address`.
- Если список адресов отдаётся другим эндпоинтом, укажите его вручную —
  команда `call` покажет сырой ответ:
  `python3 f2c_inventory.py call GET /api/organizations/10/addresses`.
