# Веб-GUI для analyzer.sh

Браузерный интерфейс аудита веб-ресурсов: вместо запуска `analyzer.sh` из
терминала — форма ввода URL, карточки метрик (DNS, TCP, TLS, TTFB, общее
время), таблица заголовков и полный JSON-отчёт.

Сервер написан на **стандартной библиотеке Python 3** — никаких новых
зависимостей у репозитория не появляется.

## Запуск

```bash
python3 gui/server.py                  # 0.0.0.0:8000
python3 gui/server.py --port 8080
python3 gui/server.py --host 127.0.0.1 # только локально
```

Откройте `http://localhost:8000/` в браузере.

## Возможности интерфейса

* ввод URL (схема дополняется автоматически: `example.com` → `https://…`);
* дополнительные опции: общий таймаут, таймаут соединения, максимальный
  размер тела, следование редиректам;
* карточки метрик соединения: DNS / TCP / TLS / TTFB / общее время;
* сводка: статус (`success` / `partial` / `error`), HTTP-код, редиректы;
* таблица заголовков (`Content-Type`, `Server`, HSTS, `Content-Length`)
  и содержимого (`<title>`, размер, сжатие);
* полный JSON-отчёт с кнопкой «копировать».

## HTTP API

GUI-сервер даёт простое API — им можно пользоваться и без браузера:

### `POST /api/audit`

Тело запроса (JSON):

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `url` | string | — (обязательно) | URL для аудита |
| `timeout` | int | 30 | общий таймаут, с (1–120) |
| `connect_timeout` | int | 10 | таймаут соединения, с (1–60) |
| `max_size` | int | 10 МБ | максимальный размер тела, байт (0–100 МБ) |
| `follow_redirects` | bool | false | следовать HTTP-редиректам |

Ответ:

```json
{
  "ok": true,
  "exit_code": 0,
  "report": { "...": "JSON-отчёт analyzer.sh (см. docs/ANALYZER.md)" },
  "stderr": "",
  "duration": 0.35
}
```

`report` — тот же отчёт, что и у `analyzer.sh --json-only`
(схема описана в [docs/ANALYZER.md](ANALYZER.md)); `exit_code` — код
возврата analyzer.sh (3 — невалидный URL, 4 — сетевая ошибка и т.д.).

Пример:

```bash
curl -s -X POST http://localhost:8000/api/audit \
  -H 'Content-Type: application/json' \
  -d '{"url": "example.com", "follow_redirects": true}' | jq .report.timings
```

### `GET /api/health`

Проверка живости сервера и доступности `analyzer.sh`:

```json
{"ok": true, "analyzer": true, "analyzer_path": "/…/analyzer.sh"}
```

## Безопасность

* URL и опции передаются analyzer.sh **только массивом аргументов**
  (`subprocess.run` без `shell=True`) — инъекции команд невозможны;
* валидация схем URL выполняется самим analyzer.sh (`http`/`https`,
  код 3 для `file://`, `javascript:` и т.п.);
* управляющие символы в URL отклоняются ещё на стороне GUI (HTTP 400);
* аудит выполняется в режиме `--json-only` — артефакты (HTML, заголовки)
  на диск не сохраняются;
* числовые опции ограничены сверху (таймаут ≤ 120 c, размер ≤ 100 МБ);
* одновременные аудиты ограничены (по умолчанию 4), лишние получают 429;
* субпроцесс запускается с минимальным окружением и жёстким таймаутом
  (`timeout + 15 c`).

GUI рассчитан на локальное/доверенное использование (инструмент
разработчика). Для публикации в интернет добавьте reverse-proxy
с аутентификацией.

## Тестирование

```bash
./tests/run_gui_tests.sh
```

Смоук-набор поднимает GUI-сервер и локальный HTTP-сервер (`tests/server.py`)
и проверяет: выдачу страницы, `/api/health`, успешный аудит, HTTP 404 →
`partial`, запрещённую схему (exit 3), пустой URL и битый JSON (HTTP 400),
неизвестный маршрут (404) и `--follow-redirects` через API.
